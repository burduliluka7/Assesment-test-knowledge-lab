# Inspection of actual clean-run outputs

Codex inspected these generated outputs programmatically and by reading their text. This is not a human scientific adjudication.

- Gates A/B: read the first ten anomaly records. h_00344/346/347/348/349 have edge year 2017 but endpoint/asserting-paper visibility 2018; h_00351/352/353/354/355 have edge year 2021 but required visibility 2024. Deferral to the maximum required year is consistent with the stated rule.
- Input preservation check found the clean ground-truth copy one byte shorter than the supplied original, with identical parsed JSON. Restored the exact original bytes before either verified run loaded gold for scoring, refreshed both manifests, and retained the before/after hashes in input_copy_correction.json. All four clean input files now match their parent supplied files byte-for-byte. The parent inputs were never modified.
- Gate D: native temporal 2020 has 12/40/120/1505 clusters, with validated partition and parent invariants. Inspected primary largest clusters across snapshots: L0 sizes 941/1353/2429/3765, L1 761/1110/1957/3043, L2 641/917/1608/2615. This is strong size imbalance. Fixed count budgets do not enforce balanced communities or interpretable natural scales. No balance penalty was introduced after inspection.
- Gate F: inspected primary birth, continuation, growth, merge and split examples. L0_2020_0001 continues with all 128 members; L0_2020_0000 retains 941 old members and grows. A level-1 merge has two equal two-node contributions; a level-0 split distributes 3/12 and 9/12 old members. No primary death event is observed in this cumulative corpus; absence is retained as null, not fabricated. Events refer to membership, not scientific history.
- Event definitions are nonexclusive: `growth` means a retained primary identity acquired at least one member relative to its predecessor, even if other members departed; it is gross membership acquisition, not necessarily positive net size change. `continuation` means a retained identity with no acquired members. `birth`/`death` require no overlap, while all nonzero overlaps are saved separately. Hungarian primary identities and significant merge/split relations can coexist. These choices are bookkeeping, not evidence of a scientific event.
- Direct partition recomputation confirms temporal ARI gains in 2020→2022 and 2022→2024, but all three 2024→2026 temporal ARIs are slightly lower than static: L0 0.7604 vs 0.7651, L1 0.7820 vs 0.7892, L2 0.7717 vs 0.8527. A higher descriptive average cannot be described as improvement at every transition. The last-transition limitation is visible in the temporal-stability figure and full table.
- Gate G: read all 40 required primary examples (five L0 and five L1 per year) from gate_G.json and checked exact generation packets. Common labels are materials, carbon, prediction, descriptor, parallel, feature and Scientific evidence. They are conservative but often too generic to navigate well. A few nonauthor cited_work nodes have author-like names (Ren et al., Smith et al.) and appear in representative lists despite exclusion of author-type nodes. This is a residual data/type and labelling limitation, not proof of author-free semantics. Some copied names include punctuation or performance wording; the template only says the cluster contains such evidence, but NLI may nevertheless interpret the name as a claim.
- The NLI tokenizer emitted an over-length warning while counting untruncated input tokens. Actual inference uses premise-only truncation to the configured maximum, and both input lengths and truncation flags are exported. This warning alone does not show an out-of-range model forward pass.
- The two completed label-faithfulness JSON files match byte-for-byte. Primary temporal has 208 labels, 174 evaluable and 34 unavailable; among evaluable labels, 120 entailment, 37 neutral and 17 contradiction predictions yield a 54/174 = 0.3103448 overclaim proxy. Thirty-one primary packets have character or token truncation. These are regenerated values, not historical reuse. The 2020 `lda` gloss with citation-like representative names receives 0.938 entailment, illustrating why machine entailment cannot certify a good scientific label.
- Ultralight review limitations are accepted as described in review_decisions.md: first-hit work depends on scan order; generation names can be absent from held-out evidence; source overlap is not strict claim correctness; direct identity and composite document recovery are different units.
- Frozen prediction inspection before completed report: all five systems recover zero complete Type-A targets at 10/25 under the declared direct-identity/composite-bundle rule. Q3 directly ranks DeepH-E3 at 57 even though top documents contain its name as context; Q12 MatterSim is at 31; Q1 and Q8 top results are predominantly claims/problems/future topics. The broad leaf pool and verbose-context preference can return relevant evidence without ranking the exact gold identity. Full node/target rank samples are in retrieval_failure_inspection.json. This is a negative downstream result, not evidence that the graph contains no relevant information. No candidate-type restriction, alias expansion or score adjustment was introduced to rescue it.

Acceptance of an execution gate certifies the specified data/code invariant. It does not certify scientific usefulness, faithful labels or superior retrieval. Weak observed outputs remain part of the assessment.
