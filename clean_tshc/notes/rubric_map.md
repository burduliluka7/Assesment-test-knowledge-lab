# Assessment evidence map

This map identifies implementation and measured evidence. Final acceptance is determined by the executed output audit and Gate K, not by checked boxes in a planning document.

| Requirement | Implementation | Inspectable evidence |
| --- | --- | --- |
| Deliverable 0 / T2 | hierarchy.py exact Ward, native entropy and shared-node VI merge deltas; hypergraph.py | Report objective, fixed configuration, delta-versus-full-objective and heap-selection tests; four variants |
| T1 input/temporal audit | data.py, snapshots.py, audit_data.py | Input SHA/schema manifest, 170/134 freshly counted anomalies, ten inspected examples, strict four-snapshot JSON and growth/arity tables/figures |
| P1/P2 laminarity and budgets | Merge-only hierarchy; validate at every build | Synthetic tests plus full-output parent/child/member/size audit for all 16 hierarchies |
| T3 / P5 | Same-level previous partition enters merge objective; Hungarian identity after construction | Stage lambda logs, real ARI/VI/lineage metrics, complete overlaps, valid birth/continuation/growth/merge/split/death tests and observed events |

| T5 / P6 | Generation-only TF-IDF and representatives; type-stratified hash split | Exact inputs, held-out packets, deterministic/future-evidence tests, 40 inspected primary examples, overclaim proxy with probabilities and limitations |

| Benchmark validity | Evaluation-only nonexact annotations and source/claim alignment | Heterogeneous target status audit, partial never full credit, absent not fabricated, unjudged returns, null unevaluable claims, provenance separate from claims |
| Isolation | Separate construction modules and evaluation import after prediction freeze | Source isolation tests, altered-gold prediction invariance, model revisions and prediction hash checks |
| T7 clarity / reproducibility | One entry point; default YAML; exact installed dependency versions | Generated concise report, README, six static figures, AI-use disclosure, verified references, source manifests, complete fresh-output/cold-vector Gate K |

The method may be a poor scientific partition or weak navigator despite satisfying structural invariants. Size imbalance, generic labels, partial benchmark support, conservative claim alignment and NLI domain mismatch are retained as findings and limitations. Neither a low null p-value nor a high lineage-retention rate alone establishes scientific usefulness.
