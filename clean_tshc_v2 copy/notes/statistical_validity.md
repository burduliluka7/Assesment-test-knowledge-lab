# Descriptive validity review

Verification Status: ANALYZED. Model inference determinism and software invariants are tested; a complete duplicate benchmark run is not claimed.

Material Passport: computational retrieval development study; supplied graph and question text; predeclared systems; gold accessed only after prediction freeze; no participant data; no inferential significance claims; report generated from machine-readable evaluation.

The following 11/11 fallacy categories were checked for applicability:

| Category | Assessment |
|---|---|
| Simpson's paradox | Aggregate metrics must be accompanied by question-level ranks and regressions; no homogeneous improvement claim. |
| Ecological fallacy | Benchmark averages do not establish success for every query or target. |
| Berkson's paradox | Questions are a selected development benchmark; no population generalization. |
| Collider bias | No covariate-adjusted causal inference is performed. |
| Base-rate neglect | Exact target counts, unresolved targets, and denominators must be shown. |
| Regression to the mean | No target-driven repeated parameter selection; pre-gold software retries are recorded. |
| Survivorship bias | Absent/partial targets and retrieval misses remain explicit; conditional direct-rank means are labeled. |
| Look-elsewhere effect | Many systems/metrics are descriptive; no significance claim or post-hoc primary model selection. |
| Garden of forking paths | Configuration is frozen and hashed; no changes after gold evaluation. |
| Correlation versus causation | Ablations describe performance differences; representation, filtering, and query effects may interact. |
| Reverse causality | No causal estimate is made; scores do not establish scientific truth or evidence entailment. |

No p-values, bootstrap confidence intervals, or calibrated probability interpretations are supplied. The already-inspected, small benchmark does not justify statistical superiority claims. Source and model hashes, deterministic synthetic probes, full ranks, and the immutable reference-tree check establish narrower computational facts.
