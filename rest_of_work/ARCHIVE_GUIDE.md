# Earlier work and development history

The main submission is in [../clean_tshc/](../clean_tshc/). The full write-up is [../clean_tshc/report/full_report.tex](../clean_tshc/report/full_report.tex), with a compiled PDF beside it.

This folder preserves the previous assessment project: source, configurations, tests, input files, experiment notes, generated artifacts and reports. Its original [README.md](README.md) is retained as a historical document; references there to a "final submission" describe that earlier stage, not the current main submission.

`clean_tshc_development/` preserves the clean implementation's earlier execution attempts and independent reproduction/reference artifacts. The accepted outputs remain in `../clean_tshc/outputs/`. Completion records distinguish successful, recovered and partial runs; their original recorded paths are intentionally preserved for provenance.

Run historical commands from this directory. Absolute paths or references between the old project and the clean project may need adjustment after this organizational move. Local environments and caches are preserved on the author's machine but excluded from GitHub; install the relevant pinned dependencies when reproducing the work.
