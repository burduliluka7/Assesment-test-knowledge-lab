    core_task: str | None,
    requirements: list[str],

# 10. REQUIREMENT-LEVEL EVIDENCE MATCHING

Do not score:

```text
whole question
vs
whole evidence bundle
```

as the main new mechanism.

Instead, for each candidate and each requirement/task:

```text
requirement r
candidate c
candidate evidence E(c)
```

compute:

```text
support(c, r)
```

using the best candidate-specific evidence.

Different evidence pieces may support different requirements.

Example:

```text
accuracy requirement
→ claim A

efficiency requirement
→ claim B

scale requirement
→ article/claim C
```

Do not require one sentence to satisfy all requirements.

# 11. CR1 — REQUIREMENT-DECOMPOSED COSINE

Implement:

```text
CR1_requirement_cosine
```

For each candidate:

1. compute semantic similarity between each requirement/task and each selected candidate-specific evidence item;
2. take the strongest valid evidence support for each requirement;
3. aggregate across requirements.

Conceptually:

```python
support_r = max(
    cosine(requirement_r, evidence_i)
    for valid evidence_i in candidate_evidence
)
```

But evidence attribution rules below MUST be applied.

Do not let arbitrary path-neighbor text qualify equally with direct evidence.

---

# 12. SEPARATE SUPPORT STRENGTH FROM REQUIREMENT COVERAGE

For candidate `c`, calculate at least:

```text
mean/max support strength
requirement coverage
```

For example:

```python
coverage =
    supported_requirements / total_requirements
```

Do not require a manually tuned threshold if avoidable.

A simple generic aggregation can be predeclared, e.g.:

```python
candidate_score =
    mean(requirement_supports)
    * mild_coverage_factor
```

or a smooth geometric/soft-min style aggregation.

The desired behavior is:

```text
Candidate A:
strong on all requirements

should outrank

Candidate B:
extremely strong on only one requirement
but unsupported on the rest
```

Do not tune aggregation weights against Q1-Q14.
