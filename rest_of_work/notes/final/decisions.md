Material Passport: supplied TKH, frozen local artifacts and user final-integration request; code/reproducibility validation; no human scientific adjudication. The final pass is development evaluation on a repeatedly used benchmark.

- FINAL_FINE is exactly the archived `without_qualifiers` control, including the existing generic shared-predicate and attribution fixes. It is CR1-derived decomposition, not a rollback of those fixes. Qualifier vectors can be loaded solely to reproduce the historical embedding-cache batch; no qualifier is scored.

- Fixed traversal budgets 25/50/100/200/500 and unrestricted. Charge coarse/prototype/leaf and candidate-component-evidence comparisons. Charge cached evidence logically per standalone run, and record actual incremental dots separately. H2 vector comparisons and sparse incidence visits remain distinct.
- Main hierarchy searches all eligible grouped entities. One reached atomic member activates its existing exact-name group and its frozen evidence pool. H2-intersection controls use the same budgets and provide a separate restricted-pool ceiling. Restricting a candidate list can itself promote lower-ranked gold targets, so intersection recall is not mathematically bounded by FINAL_FINE top10 recall.
- Flat exhaustive uses all eligible groups and the same fine scorer. Flat equal-work scans a fixed seed42 random prefix within the same total budget; no cheap-candidate skipping. It need not consume exactly the last few comparison units.
