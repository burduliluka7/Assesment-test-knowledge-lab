Top flat outputs often name generic scientific categories (for example machine-learning interatomic potentials) rather than benchmark-specific named models. This is a scorer/candidate-pool limitation even before branch pruning. Branch diagnostics record 46 missed mapped target instances with ancestor/leaf inspection status. More search need not monotonically improve top-ten relevance.

This helps explain why structural/display validity is not semantic usefulness.
