The implemented objective deliberately combines local fragmentation and global spectral geometry. Its quadratic fragmentation can also be expressed through endpoint-pair agreements; retaining native edge objects provides traceability and recursive support updates, but is not evidence that every objective term is mathematically irreducible to pairwise interactions. This distinction matters when interpreting a native-versus-projected experiment.

## Query-seeded diffusion follow-up

Primary source rechecked: Zhou, Huang and Schölkopf, [Learning with Hypergraphs: Clustering, Classification, and Embedding, NIPS 2006](https://proceedings.neurips.cc/paper_files/paper/2006/file/dff8e9c2ac33381546d96deea9922999-Paper.pdf). Section 5 defines the symmetric normalized operator; section 7 applies its resolvent to initial labels. This repository's use of query-semantic scores as the restart signal is a new retrieval adaptation, not a retrieval result claimed by that paper. The source also shows that the arity-two specialization retains a half-identity term. The pairwise control therefore uses the same lazy symmetric normalization rather than incorrectly doubling the operator.

The new implementation reuses `spectral.laplacian`, tests sparse multiplication and restarted iteration against tiny dense formulas, and compares the native incidence mechanism with the existing weight-conserving pairwise projection. A linear hypergraph diffusion operator can itself be represented as a weighted pair expansion; this experiment cannot establish irreducible higher-order expressivity merely by outperforming one chosen projection. See `hypergraph_diffusion.md` for measured retrieval outcomes and limitations.
